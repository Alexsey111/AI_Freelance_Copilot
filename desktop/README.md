# Окно программы (Electron)

Тонкая оболочка над ядром на FastAPI: окно поднимает ядро отдельным процессом, ждёт
`/api/v1/health` и показывает интерфейс. Бизнес-логики здесь нет — только запросы к API.

## Запуск

```bash
cd desktop
npm start                 # обычный запуск
npm run selftest          # самопроверка: проходит по всем экранам и проверяет данные
npm run smoke             # снимок окна в файл (по умолчанию во временную папку)
```

Первый запуск требует, чтобы в корне проекта работал `.venv` с зависимостями ядра.
Путь к интерпретатору можно переопределить переменной `FREELANCE_PYTHON`.

## Экраны

| Экран | Что делает |
|---|---|
| Профиль | имя, о себе, опыт, навыки; справочник навыков по восьми профессиям с поиском; минимальный бюджет, ставка, часы в неделю |
| Время на задачи | нормы часов по типам задач (18 заводских, от правок до сайта), правка нормы, проверка оценки конкретного заказа с объяснением |
| Загрузка недели | занято, свободно, ёмкость, деньги и разбивка часов по типам задач |
| Правила | 14 правил работы: ставка, часы, цель недели, режим порога, пороги возраста и конкуренции, режим отправки откликов, цена отклика, прайс токенов |
| Очередь проверки | заказы, где система не уверена; подтвердить или отклонить |
| Заказы | выбор площадок, предупреждение о платности отклика, кнопка «Обновить ленту с площадок», подборка под профиль с причиной по каждому заказу |
| Площадки | тарифы площадок: бесплатный лимит, цена попытки, модель оплаты, ссылка на источник и оговорки |
| Отклики | журнал отправленных откликов и воронка: доля ответов, доля наймов, цена одного найма; выбор площадки подставляет цену попытки |
| Прогоны | сколько заказов разобрано, сколько ушло человеку, токены и стоимость прогона |

## Как проверяется

- `--selftest` поднимает ядро, ждёт готовности, читает все экраны через настоящий API и
  падает, если данных нет. Печатает `SELFTEST_OK` и выходит с кодом 0.
- `--smoke --smoke-out <файл>` делает снимок окна: единственный способ убедиться, что
  страница действительно нарисовалась.
- Служебные прогоны работают в отдельном профиле (`userData` во временной папке) и не
  берут блокировку единственного экземпляра, поэтому не мешают открытому окну.

## Что нужно знать при доработке

- Скрытое окно не рисуется: перед `capturePage()` окно показывается, а на сам захват
  ставится сторожевой таймер. Ожидание события `did-finish-load` после загрузки страницы
  вешает проверку навсегда — подписываться на него в этот момент нельзя.
- У страницы отключено троттлинг фоновых таймеров (`backgroundThrottling: false`),
  иначе `setTimeout` в скрытом окне растягивается на минуты и любая проверка «висит».
- Внешние ссылки уходят в системный браузер, навигация внутри окна запрещена.
- Размер и положение окна хранятся в `userData/window.json`; данные — в базе ядра, не здесь.
