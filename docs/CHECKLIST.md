Состояние на момент проверки: всё ниже проверено запуском, а не заявлено.

## Функциональный чек-лист

- [x] Точка 1 создаёт заказ и возвращает `id` + `status` (201)
- [x] Точка 2 отдаёт витрину с пагинацией, фильтрами `status`, `needs_review`, `source`,
      `recommendation` и поиском
- [x] Точка 3 запускает ИИ-анализ и возвращает результат строго по схеме ТЗ §12
- [x] 4 доменные таблицы + `audit_runs`
- [x] Каждый запуск пишется в аудит: `action`, `input`, `output`, `status`, `error`, `duration_ms`
- [x] Аудит сохраняется и при ошибке (404 по несуществующему заказу, timeout модели)
- [x] `needs_review=true` + непустая причина проверки
- [x] Результат, ушедший на проверку, безопасен: `match_score=null`, `draft_reply=null`
- [x] Невалидный JSON модели не роняет приложение, а уходит человеку
- [x] Ручная проверка: подтвердить/отклонить, решение в аудите, статус заказа меняется
- [x] Веб-панель: 6 экранов, включая карточку с сырым вводом/выводом
- [x] Метрики с правилом «нет данных ≠ ноль»
- [x] Мини-экономика: 13 мин → 3 мин на заказ, ≈16,7 ч на 100 заказов
- [x] Все тесты работают без сети и без затрат (mock-провайдер)
- [x] Docker: оба контейнера собираются и поднимаются, backend `healthy`, панель отдаёт данные
      из контейнерного backend (проверено на портах 8300/8601, см. `docs/DOCKER.md`)

## Что требует вашего участия

- [ ] **Реальный LLM.** Все прогоны сделаны на `mock`. Переключение на реальную модель
      описано в `README.md`; это тратит деньги, поэтому без вашей команды не делалось.
- [ ] **Порты 8000 и 8501 на вашей машине заняты** другими проектами
      (`faceid-core-api` слушает 8000). Для Docker используйте
      `BACKEND_PORT=8300 FRONTEND_PORT=8601 docker compose up -d`.
- [ ] **Скриншоты для отчёта.** Панель проверена через браузер (экраны работают),
      но для сдачи нужны ваши скриншоты с вашими комментариями.
- [ ] **Раздел «мини-экономика» в отчёте** должен содержать фактические замеры времени человека,
      а не оценку 13/3 минуты (см. `docs/ECONOMICS.md`, п. 2).
