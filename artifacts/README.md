# artifacts — результаты прогона набора тестовых данных

Каталог создаётся скриптом и не коммитится (`.gitignore`): содержимое воспроизводится
одной командой на чистой базе.

```bash
./.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000   # терминал 1
rm -f data/app.db
./.venv/Scripts/python.exe scripts/run_tests_data.py                              # терминал 2
```

| Файл | Что внутри |
|---|---|
| `scenarios-<штамп>.json` / `.csv` | все 15 сценариев: заказ, решение, оценка, `needs_review`, причина, статус аудита, флаг совпадения со спецификацией |
| `showcase-<штамп>.json` / `.csv` | витрина заказов: то, что отдаёт `GET /api/v1/orders` |
| `audit-<штамп>.json` / `.csv` | журнал `audit_runs` целиком: действие, статус, длительность, ошибка |
| `metrics-<штамп>.json` | метрики и мини-экономика: `json_valid_rate`, `review_share`, распределения, экономия |

CSV разделены точкой с запятой и сохранены в UTF-8 с BOM — так их открывает Excel без танцев
с кодировкой. Это и есть «экспорт» из требований сдачи.
