# Миграции

Каталог зарезервирован под миграции схемы (Alembic). В MVP схема создаётся
автоматически при старте приложения (`Database.create_all()`), потому что таблиц всего
пять и они не меняются по ходу работы. При переходе на PostgreSQL и появлении первых
изменений схемы здесь размещается `alembic init migrations` без правок бизнес-логики.
